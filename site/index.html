        How it works

        • Both the tipper and the recipient must hold an Agent ID (checked on-chain, balanceOf on the Agent ID contract).
        • Minimum tip 0.0001 BNB. Message up to 140 characters.
        • The contract forwards the full amount immediately — no custody, no fees, no owner, no admin functions.
        • Name lookup uses a local index (names.json) of Agent ID names verified with the Binance Agentic Wallet resolver plus on-chain checks. A name not in the index yet can still receive tips: paste the recipient's 0x address instead and the site verifies their Agent ID on-chain before you send.
        • Contract: not deployed yet

        AgentTip — an entry for the Agent ID Hackathon (BNB Chain). No returns are promised; a tip is a gift, not an investment.
